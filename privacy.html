制定日：2026年10月15日

カプラメー（以下「当サイト」）における、個人情報や利用状況の取り扱いについて定めます。

ツールで入力したデータについて

当サイトのツールに入力した記録や設定は、お使いのブラウザの中にだけ保存されます。当サイトの運営者や外部のサーバーに送信されることはありません。

ブラウザの履歴やサイトデータを削除すると、保存した内容も消えます。別の端末やブラウザとは共有されません。

広告について

当サイトでは、第三者配信の広告サービス「Google アドセンス」を利用することがあります。

Google などの広告配信事業者は、Cookie を使って、当サイトや他のサイトへの過去のアクセス情報に基づいた広告を表示することがあります。Cookie に氏名や住所などの個人を特定できる情報は含まれません。

Google による情報の扱いについてはGoogle のポリシーと規約をご覧ください。パーソナライズ広告は広告設定から無効にできます。

当サイトでは、Amazon アソシエイトなどのアフィリエイトプログラムを利用することがあります。紹介した商品のリンクから購入があった場合、当サイトに紹介料が支払われることがあります。

外部サービスについて

当サイトは GitHub Pages で公開しており、文字の表示に Google Fonts を利用しています。ページを表示する際、これらのサービスにアクセス元の IP アドレスなどが送信されることがあります。取り扱いは各サービスのプライバシーポリシーに従います。

アクセス解析について

当サイトでは、アクセス状況を把握するために Cloudflare Web Analytics を利用しています。閲覧したページや参照元、おおまかな地域、端末の種類などを集計しますが、Cookie は使用せず、個人を特定する情報は収集しません。

取り扱いの詳細は Cloudflare のプライバシーポリシーをご覧ください。
