# カプラメーの文面の書き方

2026年10月の文面見直し(森田さんによる31か所の修正)から拾った基準です。
説明ページやタイルの文面を新しく書くとき・直すときは、これに合わせます。

## 全体
- 事実だけを短く書く。安心させたり売り込んだりする一言は入れない
  (例:「広告なし」「どこにも送信されません」「アプリのように使えます」「〜がおすすめです」)
- 「とき」は漢字で「時」、「くりかえし」は「繰り返し」を基本にする
- 1つの欄に2文あって長いときは、文の区切りで改行してよい(改行はそのまま表示される)

## 欄ごと
- **タイルの説明**:一文の体言止め。「〜するクロッキー練習用のビューワー。」のように句点で終える
- **一行説明**:タイルの説明と同じくらい短く。体言止め(「〜タイマー。」「〜アプリ。」)でも、です調でもよい
- **ボタン下の補足**:必要な手順だけ(例:インストール不要、ダブルクリックで起動)
- **こんなときに**:「〜したい時」で終え、句点は付けない。思いつかないツールでは無理に作らず空にする
- **使い方/遊び方**:1項目1〜2文。各項目の最後に「。」を付ける
- **主な機能**:キー操作など、使い方に書ききれない操作情報があるときだけ書く。機能の羅列はしない
- **対応環境**:「スマホ・PCのブラウザ」のように短く
- **データの保存**:「〜はこの端末のブラウザの中に保存されます。」で統一。
  端末間で移す方法が必要なツールだけ、改行して2文目を足す

## 英語版
- 日本語の内容をそのまま訳す。日本語で消した項目は英語でも消す
- 手順の各項目は英語でもピリオドで終える
