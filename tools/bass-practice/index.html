ベース練習帳

課題曲、YouTubeの区間ループ、基礎練メニュー、メトロノームをまとめた、ベース練習用のWebアプリです。

A bass practice web app with a song list, YouTube A–B looping, basic drills and a metronome.

開く →

こんなときに

  • 練習したい曲と参考動画を、ひとまとめにしておきたいとき
  • 動画の難しいところだけをくり返し聴きたいとき
  • Keeping your practice songs and reference videos in one place
  • Looping just the tricky part of a video

使い方

  1. 「曲を追加」で課題曲と練習用のYouTube動画を登録します
  2. 動画の区間ループや速度変更で、難しいところをくり返し練習します
  3. 基礎練メニューとメトロノームも同じアプリの中で使えます
  1. Add a song along with a YouTube video to practice with
  2. Use A–B looping and playback speed to drill the hard parts
  3. Basic drills and the metronome live in the same app

主な機能

  • YouTubeの区間ループ・速度変更・ブックマーク
  • 基礎練メニューをカテゴリ分けして管理
  • メトロノーム(拍子・刻み・タップでテンポ指定・曲のBPMから設定)
  • データの書き出し・読み込み(JSON)
  • YouTube A–B looping, speed control and bookmarks
  • Basic drills organized by category
  • Metronome with time signature, subdivision, tap tempo and per-song BPM
  • Export and import your data as JSON
対応環境
スマホ・PCのブラウザPhone and desktop browsers
データの保存
データはこの端末のブラウザの中に保存されます。PCとスマホで移すときは、片方で書き出してもう片方で読み込んでください。Data is saved in this device's browser. To move it between devices, export on one and import on the other.
