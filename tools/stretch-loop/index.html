ストレッチループ

ストレッチの秒数をくり返し計るループ式のタイマー。

A looping interval timer for stretching.

開く →

こんなときに

  • 左右30秒ずつなど、同じ秒数を何度もくり返してストレッチしたい時
  • シンプルなタイマーがほしい時
  • When you want to repeat the same interval, such as 30 seconds per side
  • When you just want a simple timer

使い方

  1. 「ラップ設定」で1回の秒数を決めます。ラップは追加できます。
  2. 画面をタップするとスタート。ラップを順番に繰り返します。
  3. 「リセット」で最初に戻ります。
  1. Set the length of one lap in the lap settings. You can add more laps.
  2. Tap the screen to start. The laps repeat in order.
  3. Tap reset to start over.
