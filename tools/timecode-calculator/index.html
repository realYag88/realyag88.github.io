TimeCode Calculator

フレーム数と24fps・30fpsのタイムコードを相互に換算できる電卓です。解像度の縦横比計算もできます。

A calculator that converts between frame counts and 24fps / 30fps timecode. It also has a tab for aspect-ratio resizing.

Web版を開く → Windows版をダウンロード(.exe)

Windows版はインストール不要で、ダウンロードしたexeをダブルクリックするだけで使えます。初めて開くときに「WindowsによってPCが保護されました」と出た場合は、「詳細情報」→「実行」を押してください(個人で作ったアプリに署名がないために出る表示です)。

The Windows version needs no installation; just double-click the exe. If Windows shows “Windows protected your PC” the first time, click “More info” → “Run anyway” (this appears because the app is not code-signed).

こんなときに

  • カットの尺を、フレーム数と秒+コマで行き来したいとき
  • 24fpsと30fpsで尺がどう変わるか確かめたいとき
  • 素材を縦横比を保ったままリサイズしたいとき
  • Going back and forth between frame counts and seconds + frames
  • Checking how a duration maps between 24fps and 30fps
  • Resizing footage while keeping its aspect ratio

使い方

  1. 数字を入力して表示部をクリック(タップ)すると、FRAME → 24FPS → 30FPS の順に換算されます
  2. タイムコードは右から詰めて入力します。「210」と打つと2秒10コマです
  3. 普通の電卓としても使えます。24FPS・30FPSのときの足し算・引き算は、そのままタイムコードの計算になります
  4. 「解像度」タブでは、元サイズと変換後の幅か高さを入れると、もう一方がすぐに出ます(端数は切り上げ)
  1. Type a number and click (tap) the display to convert: FRAME → 24FPS → 30FPS
  2. Timecode is entered from the right: typing “210” means 2 seconds 10 frames
  3. It also works as a normal calculator; adding and subtracting in 24FPS / 30FPS mode works in timecode
  4. In the resolution tab, enter the original size and a new width or height to get the other side (rounded up)

主な機能

  • キーボード操作:Enter=「=」/ Esc=C / Delete=CE / Backspace=1文字消す / Tab=モード切替
  • Web版は Alt+1・Alt+2 でタブ切替(Windows版は Ctrl+Tab)
  • 解像度タブの元サイズは、次に開いたときも残ります
  • Keyboard: Enter = “=”, Esc = C, Delete = CE, Backspace = delete one digit, Tab = switch mode
  • Switch tabs with Alt+1 / Alt+2 on the web (Ctrl+Tab in the Windows app)
  • The original size in the resolution tab is remembered
対応環境
Web版:スマホ・PCのブラウザ / Windows版:Windows 10・11Web: phone and desktop browsers / App: Windows 10 and 11
データの保存
Web版は元サイズの設定だけをこの端末のブラウザに保存します。The web version only saves the original size setting in this device's browser.
